# README

## Build and Run Instructions

### Clone the Repository

```sh
git clone https://github.com/davidgcs/backendDevTest.git
cd ./backendDevTest/frontend
```

### Install Dependencies

```sh
npm install
```

### Build the Project

```sh
npm run build
```

### Run the Application

```sh
npm start
```

**Access the App**
Open your browser and navigate to `http://localhost:4200` (or the port specified in your configuration).

## Requirements

- Angular/CLI 20
- Node.js (v16+ recommended)
- npm

## Testing

- Run the tests with:

```sh
npm run test
```

- Run the code check with:

```sh
npm run lint
```
